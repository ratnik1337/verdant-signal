# Исходный артпак: аудит

Проверен архив с 82 файлами. Детальная строка на каждый файл с размером, альфой, видом, точкой опоры, pivot, допустимостью прямого использования и нужной доработкой находится в [ASSET_AUDIT.csv](ASSET_AUDIT.csv).

Общие правила стиля по доступным исходникам: полированные объёмные 3D-иконки; насыщенные локальные цвета; мягкие градиенты и блики; преимущественно фронтальная/трёхчетвертная камера. Это не одна единая камера для всех игр: футбольный keeper выглядит ближе к реалистичному 3D, Mines основан на UI-скриншоте, а Aviator — на глянцевом игрушечном самолёте. Поэтому нельзя считать все исходники взаимозаменяемыми или единой художественной сценой.

| Группа | Что доступно | Прямое использование | Основная проблема |
|---|---|---|---|
| Aviator | самолёт, винт, несколько VFX-atlas и одна реконструированная горная подложка | возможно после калибровки масштаба/anchors | mount и in-game scale не заданы; нет полной фоновой сборки |
| Chicken | один idle-цыплёнок, один фургон | только простые transform-clips | нет референса, дорожных плиток, authored поз и теней |
| Apple Fortune | whole/bitten apple, одна blank tile, character concepts | яблоки/tile применимы с проверкой масштаба | плитка реконструирована, состояния/стыки не экспортированы |
| Mines | screenshot сцены | только reference | isolated gem/mine/tile не найдены; клипы — placeholders |
| Football | один generic keeper concept | концепт, не production персонаж | нет kicker, ball, goal/net и roster variants |

Среда проверки исходника: дата 2026-09-15; все новые status/anchor оценки явно помечены как оценки и не выдаются за калиброванные факты.
